# Voice Input

**Говорите — текст появляется в нужном поле.**

Voice Input распознаёт русскую речь на вашем Mac. Подходит для сообщений,
заметок и других текстов. Без регистрации и подписки. Записи никуда не отправляются.

Работает на **Mac с чипом M1 или новее и macOS 14 или новее**. На Mac с Intel не работает.

## Скачать и установить

**[Скачать Voice Input](https://github.com/ababinok/voice-input/releases/latest)**

1. На странице загрузки выберите файл с окончанием **.dmg**.
2. Откройте его и перетащите значок **Voice Input → Программы** по стрелке.
3. Откройте **Voice Input** из папки «Программы».

## Первый запуск

Приложение попросит два разрешения:

- **Микрофон** — чтобы слышать вашу речь.
- **Универсальный доступ** — чтобы вставлять текст в другие приложения.

Дождитесь сообщения **«Whisper Turbo готова»**. При первом запуске скачиваются файлы
для распознавания речи — около 650 МБ. После этого можно работать без интернета.

## Как надиктовать текст

1. Нажмите на поле, куда хотите ввести текст.
2. Нажмите **⌘ + ` / ё** — клавиша слева от цифры **1** вместе с Command.
3. Дождитесь **«Слушаю…»** и говорите.
4. Нажмите то же сочетание ещё раз. Текст появится в поле после распознавания.

**Текст не вставился? Нажмите ⌘V** — он уже скопирован в буфер обмена.

Чтобы отменить запись, нажмите крестик на панели. Настройки и выход — через
значок Voice Input в верхней строке экрана.

## Полезно знать

- Открывайте Voice Input перед использованием: автоматически он не запускается.
- Во время диктовки оставайтесь в нужном поле. Если перейти в другое, текст может остаться только в буфере.
- Текст всегда копируется в буфер обмена, заменяя то, что было скопировано раньше.
- Записи и история диктовок не сохраняются.
- Перед отправкой проверьте текст: распознавание и знаки препинания иногда ошибаются.

## Как обновить

Завершите Voice Input через его значок в верхней строке экрана. Скачайте новую
версию и снова перетащите её в **«Программы»**, подтвердив замену. Затем откройте
приложение. Файлы для распознавания речи скачивать повторно не нужно.
