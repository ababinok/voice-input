# Voice Input

Голосовой ввод для **Mac с Apple Silicon (M1 и новее), macOS 14+**.
Распознаёт русский текст на самом Mac и вставляет его в активное поле.
Без сервера, аккаунта и подписки.

## Установка

1. [Скачайте DMG из последнего релиза](https://github.com/ababinok/voice-input/releases/latest).
2. Откройте его и перетащите **Voice Input** в **Applications («Программы»)**.
3. Извлеките DMG. Запустите приложение через **⌘Пробел → Voice Input**.

Приложение без Developer ID и нотарификации Apple. Если macOS блокирует запуск,
после попытки открытия зайдите в **Системные настройки → Конфиденциальность
и безопасность → Всё равно открыть**. Делайте это только для доверенной копии.

При первом запуске дождитесь скачивания модели (~626 МБ плюс словарь).
Разрешите микрофон и «Универсальный доступ» для автоматической вставки.
После подготовки интернет не нужен. У каждого пользователя своя загрузка и разрешения.

## Как пользоваться

- **⌘ + физическая клавиша ` / ё** — начать запись; ещё раз — распознать.
- Текст вставится в исходное поле. Если вставка недоступна — нажмите **⌘V**.
- Отмена — крестик на панели. Выход и настройки — через значок в строке меню.

Приложение запускается вручную. Пока оно работает, сочетание заменяет переключение
окон. Аудио и история не сохраняются. Текст остаётся в буфере, заменяя прежнее содержимое.
В некоторых редакторах автоматическая вставка недоступна. Пунктуация может ошибаться.

## Обновление

Завершите приложение через меню и установите новый DMG с заменой старой версии.
Модель скачивать заново не нужно.

## Сборка из исходников

Нужны Apple Silicon, macOS 14+ и Xcode Command Line Tools со Swift 5.10+.
При необходимости установите инструменты командой `xcode-select --install`.

```sh
git clone https://github.com/ababinok/voice-input.git
cd voice-input
./scripts/test.sh
./scripts/build-app.sh
```

В `dist/` появятся `.app`, ZIP и `Voice-Input-1.0.0-arm64.dmg`.
Закройте копию из `dist/` перед пересборкой. Готовую `.app` перенесите в «Программы».
Для пересоздания только DMG: `./scripts/build-dmg.sh`.

Первая сборка создаёт постоянную локальную подпись; macOS может запросить подтверждение.
Ключи хранятся отдельно, в `~/Library/Application Support/VoiceInputSigning`.
Не удаляйте и не передавайте этот каталог: он сохраняет идентичность будущих сборок.
При переходе на сборку другого автора разрешения может потребоваться выдать заново.

## Выпуск версии

Измените версию в `scripts/Info.plist`, выполните тесты и сборку.
В GitHub → Releases создайте релиз с тегом версии и прикрепите DMG из `dist/`.
Архивы исходников GitHub добавляет автоматически. `dist/`, модель и ключи в Git не нужны.
