# Voice Input

Локальный голосовой ввод для Mac с Apple Silicon и macOS 14+.

## Запуск

Откройте `dist/Voice Input.app` (можно предварительно перенести в «Программы»).
При первом запуске приложение скачивает Whisper large-v3-turbo (~626 МБ плюс словарь)
и готовит её для вашего Mac. Это может занять несколько минут. Дождитесь «Модель готова».

Нажмите «Разрешить» у микрофона. Для автоматической вставки включите Voice Input
в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ».
Без этого разрешения диктовка работает с копированием в буфер.

Сверните окно настройки, установите курсор в нужное поле:

1. **Cmd + физическая клавиша ` / ё** — начать запись.
2. Произнесите текст. Полоски показывают реальный уровень звука.
3. То же сочетание — остановить и распознать.
4. Текст вставляется, если исходное поле осталось активным. В остальных случаях
   появится «Текст в буфере — нажмите ⌘V».

Сочетание привязано к ANSI Grave (код 50), а не символу текущей раскладки.
Пока приложение открыто, оно заменяет стандартное переключение окон Cmd + `.
При конфликте приложение сообщает об ошибке; настройки macOS самостоятельно не меняет.
Меню с иконкой волны открывает настройки и позволяет завершить приложение.
Автозапуска нет. Максимальная запись — 30 минут, затем распознавание запускается автоматически.

## Данные и ограничения

- Аудио обрабатывается локально и хранится только в памяти до окончания текущей операции.
- Истории записей и распознанного текста нет. WhisperKit не выводит текст в логи.
- Модель и токенизатор: `~/Library/Application Support/VoiceInput`.
- Распознанный текст заменяет текущее содержимое системного буфера обмена, в том числе
  при успешной вставке. Предыдущее содержимое буфера не восстанавливается.
- Вставка выполняется обычным Cmd + V, без Enter. Нестандартные редакторы,
  защищённые поля и поля, не предоставляющие Accessibility-информацию, получают только буфер.
- После отправки Cmd + V приложение не может гарантировать, что сторонний редактор принял текст;
  копия всегда остаётся в буфере. Фокус проверяется непосредственно перед отправкой.
- На очень тихом звуке и фоновых шумах возможны ошибки распознавания.
- Сборки подписываются одним постоянным локальным сертификатом: идентичность приложения
  сохраняется при обновлениях. При переходе со старой ad-hoc версии доступ нужно выдать
  один раз заново. Обычный перезапуск не меняет подпись.

## Сборка и передача

Нужны Xcode Command Line Tools со Swift 5.10+. Закройте приложение перед сборкой:

```sh
./scripts/build-app.sh
./scripts/test.sh
```

Сборка создаёт `.app` и `dist/Voice-Input-macOS-arm64.zip`.
ZIP можно передать другому владельцу Mac с Apple Silicon: зависимости встроены,
модель загрузится при первом запуске. Приложение подписано постоянным локальным сертификатом, без
Developer ID / нотарификации. Gatekeeper на другом Mac может потребовать разрешить
запуск через «Конфиденциальность и безопасность → Всё равно открыть».
Не отключайте Gatekeeper целиком.

## Постоянная подпись

При первой сборке `scripts/sign-app.sh` создаёт локальный сертификат на 10 лет и
закрытый ключ в отдельной связке ключей. macOS может попросить подтверждение доверия
для codesign. Доверие ограничено политикой codeSign и приложением /usr/bin/codesign
в текущей учётной записи; Gatekeeper и проверка HTTPS не отключаются.

Материалы подписи: `~/Library/Application Support/VoiceInputSigning` (каталог 700,
файлы 600). Пароль отдельной связки хранится здесь же для автоматической локальной сборки;
закрытый ключ импортирован как неизвлекаемый, временный PEM удаляется.
Эти файлы нельзя удалять или передавать с ZIP — при потере потребуется новый сертификат
и повторная выдача разрешений. При неполном комплекте сборка останавливается,
не создаёт новую идентичность и не переключается на ad-hoc автоматически.

Проверка: `./scripts/test-signing.sh` подписывает два разных тестовых бинарника,
проверяет одинаковое designated requirement и отклонение посторонней подписи.
Сборка сначала готовит и проверяет пакет в отдельной папке и лишь затем заменяет dist.

Если после перехода со старой версии переключатель доступа включён, но приложение
не видит разрешение: завершите приложение, выполните
`tccutil reset Accessibility local.voiceinput.app`, запустите его и разрешите доступ
снова. Это разовая миграция подписи, не часть обычного запуска/обновления.

## Проверка скорости

Для разработчика доступен запуск на уже существующем аудиофайле:

```sh
"dist/Voice Input.app/Contents/MacOS/VoiceInput" --benchmark-audio /absolute/path/recording.wav
```

Он загружает ту же модель, выводит распознанный текст и время подготовки/распознавания;
не включает микрофон и не изменяет буфер. Это диагностический режим, а не история приложения.
