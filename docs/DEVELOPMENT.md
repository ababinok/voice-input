# Для разработчиков

## Сборка из исходников

Нужны Apple Silicon, macOS 14+ и Xcode Command Line Tools со Swift 5.10+.
Для оформления DMG нужен Python 3.10+: закреплённые сборочные зависимости автоматически
устанавливаются в `.build/dmg-tools` при первом запуске (нужен интернет).
При необходимости установите инструменты командой `xcode-select --install`.

```sh
git clone https://github.com/ababinok/voice-input.git
cd voice-input
./scripts/test.sh
./scripts/build-app.sh
```

В `dist/` появятся `.app`, ZIP и версионный DMG, например `Voice-Input-1.0.1-arm64.dmg`.
Закройте копию из `dist/` перед пересборкой. Готовую `.app` перенесите в «Программы».
Для пересоздания только DMG: `./scripts/build-dmg.sh`.

Первая сборка создаёт постоянную локальную подпись; macOS может запросить подтверждение.
Ключи хранятся отдельно, в `~/Library/Application Support/VoiceInputSigning`.
Не удаляйте и не передавайте этот каталог: он сохраняет идентичность будущих сборок.
При переходе на сборку другого автора разрешения может потребоваться выдать заново.

## Выпуск версии

Измените версию в `scripts/Info.plist`, выполните тесты и сборку.
В GitHub → Releases создайте релиз с тегом версии и прикрепите DMG из `dist/`.
Архивы исходников GitHub добавляет автоматически. `dist/`, модель и ключи в Git не нужны.
