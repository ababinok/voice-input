# Voice Input — system map

## Назначение

Нативная утилита macOS 14+ / arm64: Cmd + ANSI Grave включает/останавливает диктовку,
WhisperKit распознаёт русский текст локально, результат копируется и по возможности
вставляется в исходное активное поле. Ручной запуск, LSUIElement, без сервера и истории.

## Компоненты

- `VoiceInputCore`: модель жизненного цикла DictationSession, правило DeliveryPolicy
  и ограниченный отменяемый повтор захвата фокуса FocusCapture.
  UUID операции предотвращает доставку отменённых/устаревших результатов.
- `AppController`: MainActor, меню, разрешения, координация задач, таймеры, статусы.
- `Recorder`: AVAudioEngine и AVAudioConverter → mono float32 16 kHz. Поток аудио
  использует отдельный защищённый lock сборщик; не обращается к UI. При смене
  конфигурации ввода пересоздаёт движок с новым форматом, сохраняя собранные сэмплы.
  До 30 минут.
- `SpeechEngine`: actor, единственный экземпляр WhisperKit. Сжатая модель
  openai_whisper-large-v3-v20240930_626MB, язык ru, один worker, VAD-разбиение.
  Короткий русский образец пунктуации передаётся как контекст стиля, без второй модели.
  Подготовка и распознавание вне MainActor. Никаких параллельных диктовок.
- `HotKey`: Carbon RegisterEventHotKey, ANSI Grave (50) + Cmd, без раскладкозависимых символов.
- `TextInsertion`: захват pid/AX-элемента и экрана, проверка текущего приложения/поля,
  редактируемости и защиты, NSPasteboard + CGEvent Cmd+V. Перед записью активирует
  Accessibility Chromium-браузеров при отсутствии поля и ограниченно повторяет
  запрос в исходном приложении/окне. Диагностика причин отказа — системный журнал
  `local.voiceinput.app`, категория `TextInsertion`, без текста и содержимого полей.
- `Views`: SwiftUI внутри AppKit; неактивирующая NSPanel не получает key/main-фокус.

## Инварианты

- Микрофон активен только при записи. Остановка, отмена, невосстановимая ошибка
  устройства и выход освобождают engine/tap. Сырые записи не пишутся на диск.
- Отмена распознавания не разрешает новую запись до завершения старого вызова;
  поздний результат отбрасывается. Повторная горячая клавиша во время обработки игнорируется.
- Панель не активирует приложение. Вставка разрешена только в тот же активный AX-элемент
  того же приложения. Нет доступа/поля/уверенности → только буфер.
- Захват поля выполняется до включения микрофона; ожидание можно отменить кнопкой
  или повторной горячей клавишей. В момент доставки новая цель не подбирается.
- Буфер всегда содержит последний непустой результат; Enter не отправляется.
- UUID проверяется до доставки. Во время доставки следующая запись блокируется.
- Успешная отправка событий не является доказательством приёма вставки чужим редактором.

## Хранение и сборка

SwiftPM, фиксированная зависимость Argmax OSS Swift 1.0.0 (используется только WhisperKit).
Package.resolved фиксирует транзитивные зависимости. Модель/токенизатор и указатель
model-path.txt расположены в Application Support/VoiceInput. Маркер пишется только
после успешной загрузки модели и токенизатора; повторный запуск загружает локальную копию.
Core ML ведёт собственный системный кэш специализации.

scripts/build-app.sh создаёт dist/Voice Input.app, копирует ресурсные bundle SwiftPM,
добавляет иконку, Info.plist/лицензии, постоянную локальную подпись, ZIP и версионный DMG.
scripts/build-dmg.sh упаковывает подписанную .app и ссылку «Программы» на /Applications
в проверенный read-only образ. scripts/dmg-settings.py задаёт компактное окно Finder
со стрелкой на Retina-фоне, создаваемом scripts/make-dmg-background.swift; текстовых
файлов внутри DMG нет. Сборочные Python-зависимости закреплены в scripts/dmg-requirements.txt
и устанавливаются в .build/dmg-tools при первой сборке (нужен интернет); в приложение
они не входят. DMG можно собрать отдельно. Постоянный bundle ID:
local.voiceinput.app. scripts/sign-app.sh хранит сертификат и закрытый ключ вне репозитория,
в Application Support/VoiceInputSigning. Идентичность привязана к сертификату и bundle ID,
а не к хешу бинарника; материалы подписи нельзя пересоздавать между обновлениями.
Сборка отказывается заменять запущенное приложение, подписывает и проверяет временный
пакет перед заменой dist. scripts/test-signing.sh проверяет стабильность идентичности
при изменении бинарника и отклонение чужой подписи.
Переход со старой ad-hoc версии требует разовой повторной выдачи разрешений.
Для публичной дистрибуции без предупреждений Gatekeeper нужна Developer ID/нотаризация.
