Voice Input — установка

Требуется Mac с Apple Silicon (M1 или новее), macOS 14 или новее.

1. Перетащите Voice Input.app на ярлык Applications («Программы») в этом окне.
2. Извлеките образ Voice Input в Finder. Не запускайте приложение прямо из DMG.
3. Нажмите ⌘Пробел, введите Voice Input и откройте приложение.

Приложение распространяется без Developer ID и нотарификации Apple.
Если macOS заблокирует запуск, сначала попробуйте открыть установленное приложение,
затем в «Системные настройки → Конфиденциальность и безопасность» выберите
«Всё равно открыть» и подтвердите запуск, только если доверяете источнику.
Не отключайте Gatekeeper и не устанавливайте чужие сертификаты.

При первом запуске дождитесь загрузки модели (~626 МБ плюс словарь),
разрешите микрофон и «Универсальный доступ» для вставки в другие приложения.
Без «Универсального доступа» текст останется в буфере обмена.
Модель скачивается на каждом Mac отдельно; после подготовки интернет не нужен.

⌘ + физическая клавиша ` / ё: начать диктовку; повторное нажатие: распознать.

Обновление: завершите Voice Input через меню, перенесите новую версию в
«Программы» с заменой прежней, затем запустите. Модель останется на месте.
При переходе между сборками разных авторов может понадобиться заново выдать доступ.
